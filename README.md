# noeta-legal

Datenschutzerklärung und Impressum der App **Noeta** — die Seite, die in App Store
Connect als Datenschutz- und als Support-URL hinterlegt ist.

**Live:** https://zanshn.github.io/noeta-legal/

Eine einzelne HTML-Datei ohne Abhängigkeiten, deutsch und englisch, hell und dunkel.

⚠️ **Die Quelle liegt im Hauptrepo unter `legal/`.** Wird der Text geändert, dort
ändern und von dort hierher kopieren — sonst laufen die beiden Fassungen auseinander.
`legal/README.md` erklärt den Weg.

⚠️ **Diese URL ist ein Pflichtfeld in App Store Connect.** Zeigt sie ins Leere, kann
Apple die veröffentlichte App beanstanden. Repository nicht privat schalten, nicht
umbenennen, Pages nicht abschalten.
